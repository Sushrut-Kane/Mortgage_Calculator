# Mortgage Calculator

A simple and user-friendly mortgage calculator that helps you estimate monthly payments, total interest, and amortization schedules.

## Features

- Calculate monthly mortgage payments
- View total interest and total amount paid
- Generate amortization schedules
- Easy-to-use interface
- Support for different loan terms and interest rates

## Getting Started

### Prerequisites

- Python 3.6+ (if applicable)
- Or a modern web browser (if web-based)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Sushrut-Kane/Mortgage_Calculator.git
   cd Mortgage_Calculator
   ```

2. Install dependencies (if applicable):
   ```bash
   pip install -r requirements.txt
   ```

### Usage

Run the calculator:
```bash
python mortgage_calculator.py
```

Or open the application in your browser and enter:
- **Loan Amount**: The principal amount borrowed
- **Interest Rate**: Annual interest rate (%)
- **Loan Term**: Duration in years

Click "Calculate" to view your results.

## Example

- Loan Amount: $300,000
- Interest Rate: 4.5%
- Loan Term: 30 years
- **Result**: Monthly Payment: $1,520.06
